Dengan hormat,

Menindaklanjuti rencana pengembangan Aplikasi Manajemen Pendapatan Asli Daerah (MPAD), diperlukan infrastruktur server yang tangguh dan aman untuk menjamin kelancaran operasional sistem secara keseluruhan.

Oleh karena itu, kami dari CV. Sarjana Komputer Indonesia mengajukan proposal untuk pengadaan Ekosistem Server Aplikasi MPAD. Ekosistem ini mencakup infrastruktur server VPS performa tinggi, langganan AI untuk coding, dan penyimpanan cloud terintegrasi.

Sehubungan dengan hal tersebut, kami mengajukan permohonan dukungan anggaran sebesar Rp 20.048.000,- (Dua Puluh Juta Empat Puluh Delapan Ribu Rupiah) untuk penyediaan ekosistem server tersebut sesuai rincian anggaran terlampir. Rincian teknis anggaran terlampir dalam dokumen ini.

Besar harapan kami agar Bapak/Ibu Kepala BAPENDA berkenan menyetujui permohonan ini untuk menjamin stabilitas dan keamanan data pendapatan daerah. Atas perhatian dan dukungan Bapak/Ibu, kami ucapkan terima kasih.
