Dengan hormat,

Menindaklanjuti rencana pengembangan Aplikasi Manajemen Pendapatan Asli Daerah (MPAD) dan kebutuhan peningkatan kapasitas infrastruktur server untuk menjamin kelancaran operasional sistem selama 1 (satu) tahun ke depan, diperlukan penguatan ekosistem server yang tangguh, aman, dan memiliki sistem pemulihan bencana (disaster recovery) yang andal.

Oleh karena itu, kami dari CV. Sarjana Komputer Indonesia mengajukan proposal pengadaan Ekosistem Server Aplikasi MPAD (1 Tahun). Ekosistem ini mencakup VPS Production performa tinggi, VPS Backup/DR, penyimpanan cloud 5TB, sistem monitoring, serta keamanan dan maintenance selama 1 tahun.

Sehubungan dengan hal tersebut, kami mengajukan permohonan dukungan anggaran sebesar Rp 38.500.000,- (Tiga Puluh Delapan Juta Lima Ratus Ribu Rupiah) untuk penyediaan ekosistem server tersebut sesuai rincian anggaran terlampir. Rincian teknis anggaran terlampir dalam dokumen ini.

Besar harapan kami agar Bapak/Ibu Kepala BAPENDA berkenan menyetujui permohonan ini untuk menjamin stabilitas, keamanan data pendapatan daerah, dan kesinambungan layanan M-PAD kepada masyarakat. Atas perhatian dan dukungan Bapak/Ibu, kami ucapkan terima kasih.
